# Ugly Number II

**Link:** https://leetcode.com/problems/ugly-number-ii/

## Problem
An **ugly number** is a positive integer whose prime factors are limited to `2`, `3`, and `5`. Given an integer `n`, return the `n`-th **ugly number**.

## Solution
We can generate ugly numbers sequentially using dynamic programming with a three-pointer approach. Since every ugly number must be generated by multiplying an already existing ugly number by `2`, `3`, or `5`:
1. We maintain three pointers `i`, `j`, and `k` representing indices of the elements in our results array that will be multiplied by `2`, `3`, and `5` respectively.
2. The next ugly number is the minimum of `results[i] * 2`, `results[j] * 3`, and `results[k] * 5`.
3. > [!IMPORTANT]
   > We use independent `if` statements (not `else if`) to increment the pointers. This handles duplicates correctly. For example, when the minimum value is `6` (which can be formed by `results[i] * 2` where `results[i]=3` or `results[j] * 3` where `results[j]=2`), both `i` and `j` are incremented. This ensures `6` is only added once to the list and prevents duplicate elements.

## Code
```cpp
class Solution {
public:
    int nthUglyNumber(int n) {    
        vector <int> results (1,1);
        int i = 0, j = 0, k = 0;
        while (results.size() < n)
        {
                results.push_back(min(results[i] * 2, min(results[j] * 3, results[k] * 5)));
                
                // Use independent if statements to increment all pointers 
                // that produced the minimum value, avoiding duplicate entries.
                if (results.back() == results[i] * 2) ++i;
                if (results.back() == results[j] * 3) ++j;
                if (results.back() == results[k] * 5) ++k;
        }
        return results.back();
    }
};
```
