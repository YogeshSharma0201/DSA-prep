# 4Sum

**Link:** https://leetcode.com/problems/4sum/description/

## Problem
Given an array `nums` of $n$ integers, return an array of all the unique quadruplets `[nums[a], nums[b], nums[c], nums[d]]` such that:
- $0 \le a, b, c, d < n$
- $a, b, c,$ and $d$ are distinct indices.
- $nums[a] + nums[b] + nums[c] + nums[d] == target$

You may return the answer in any order.

## Solution
Sort the array first. Fix the first two elements using nested loops, and use two pointers (low and high) to search for the remaining two elements that complete the target sum. Skip duplicates at each stage (first index, second index, and two-pointer update) to avoid duplicate quadruplets. Cast to `long long` when computing the sum to prevent integer overflow. This runs in O(n^3) time.

## Code
```cpp
class Solution {
public:
    vector<vector<int>> fourSum(vector<int>& nums, int target) {
        vector<vector<int>> res;

        sort(nums.begin(), nums.end());
        int n = nums.size();

        for(int i=0; i<n-3; i++) {
            if(i>0 && nums[i]==nums[i-1]) continue;

            for(int j=i+1; j<n-2; j++) {
                if(j>i+1 && nums[j]==nums[j-1]) continue;

                int low = j+1, high = n-1;

                while(low < high) {
                    long long sum = 1LL*nums[i]+nums[j]+nums[low]+nums[high];

                    if(sum == target) {
                        res.push_back({nums[i], nums[j], nums[low], nums[high]});

                        low++;
                        high--;
                        while(high > low && nums[high] == nums[high+1]) high--;
                        while(high > low && nums[low] == nums[low-1]) low++;
                    }
                    else if(sum > target) {
                        high--;
                    }
                    else {
                        low++;
                    }
                }
            }
        }

        return res;
    }
};
```

## Note: Generic K-Sum using Recursion

We can generalize the two-pointer approach to solve the $K$-Sum problem for any $K \ge 2$.
1. **Base Case ($K = 2$)**: Use the standard two-pointer approach on the sorted array.
2. **Recursive Step ($K > 2$)**: Iterate through the elements starting from the current index. For each unique element, recursively call $(K-1)$-Sum with the updated target (`target - nums[i]`) and the next start index (`i + 1`).

### C++ Recursive Solution for K-Sum

```cpp
class Solution {
public:
    vector<vector<int>> fourSum(vector<int>& nums, int target) {
        sort(nums.begin(), nums.end());
        return kSum(nums, target, 0, 4);
    }

    vector<vector<int>> kSum(vector<int>& nums, long long target, int start, int k) {
        vector<vector<int>> res;
        int n = nums.size();
        if (start == n) return res;
        
        // Optimizations: average value check
        long long average_value = target / k;
        if (nums[start] > average_value || average_value > nums.back()) {
            return res;
        }
        
        if (k == 2) {
            return twoSum(nums, target, start);
        }

        for (int i = start; i < n; i++) {
            if (i > start && nums[i] == nums[i - 1]) continue;
            for (vector<int>& subset : kSum(nums, target - nums[i], i + 1, k - 1)) {
                res.push_back({nums[i]});
                res.back().insert(res.back().end(), subset.begin(), subset.end());
            }
        }
        return res;
    }

    vector<vector<int>> twoSum(vector<int>& nums, long long target, int start) {
        vector<vector<int>> res;
        int lo = start, hi = nums.size() - 1;
        while (lo < hi) {
            long long curr_sum = nums[lo] + nums[hi];
            if (curr_sum < target || (lo > start && nums[lo] == nums[lo - 1])) {
                lo++;
            } else if (curr_sum > target || (hi < nums.size() - 1 && nums[hi] == nums[hi + 1])) {
                hi--;
            } else {
                res.push_back({nums[lo++], nums[hi--]});
            }
        }
        return res;
    }
};
```
